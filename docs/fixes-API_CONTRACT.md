# Fixes & New Endpoints — API Contract

This file documents **new or modified API endpoints** introduced as part of the Student Portal & Recruiter Portal update. The backend team should implement these to replace the current mock implementations.

---

## 1. Feature / Unfeature a Project

### `PATCH /me/projects/:id/feature`

Toggles the `is_featured` flag on a project. If the student already has **3 featured projects**, the backend must reject the request.

**Auth:** Required (student JWT)

**Path Parameters:**
| Param | Type   | Description |
|-------|--------|-------------|
| `id`  | string | Project UUID |

**Request Body:** _(empty)_

**Success Response — `200 OK`:**
```json
{
  "isFeatured": true
}
```

**Error Response — `422 Unprocessable Entity`** (when 3 projects are already featured):
```json
{
  "detail": "You can feature at most 3 projects on your recruiter profile."
}
```

## 2. Recruiter Portal — List Students in Bundle

### `GET /share/:token`

Returns the student listing for a shared bundle link.  
**This endpoint requires NO authentication.** It is publicly accessible.

**Path Parameters:**
| Param   | Type   | Description |
|---------|--------|-------------|
| `token` | string | Share token generated by a teacher |

**Success Response — `200 OK`:**
```json
{
  "token": "abc12345",
  "createdAt": "2026-07-01T00:00:00Z",
  "expiresAt":  "2026-07-31T00:00:00Z",
  "studentCount": 10,
  "students": [
    {
      "id": "uuid",
      "name": "Aarav Sharma",
      "department": "Computer Engineering",
      "batch": "2022-2026",
      "avatar": null,
      "cgpa": 9.5,
      "topSkills": ["React", "Python", "TensorFlow"],
      "featuredProjectCount": 2,
      "hasExperience": true
    }
  ]
}
```

> [!NOTE]
> `topSkills` returns a maximum of **3** skills (by proficiency descending).  
> `featuredProjectCount` counts only projects where `is_featured = true`.

**Error Response — `404 Not Found`** (expired or invalid token):
```json
{ "detail": "Share link not found or has expired." }
```

**This endpoint requires NO authentication.** It is publicly accessible.

- If the student has **no** featured projects, return the **3 most recently created** projects.

**Error Response — `404 Not Found`:**
```json

```

## 4. Create a Share Bundle (Teacher)

### `POST /share`

Creates a new share bundle and returns a token.

**Auth:** Required (teacher JWT)

**Request Body:**
```json
{
  "studentIds": ["uuid1", "uuid2", "uuid3"],
  "expiresInDays": 30
}
```

**Success Response — `201 Created`:**
```json
{
  "token": "abc12345",
  "shareUrl": "https://portfolio.mitwpu.edu.in/share/abc12345",
  "createdAt": "2026-07-06T00:00:00Z",
  "expiresAt":  "2026-08-05T00:00:00Z",
  "studentCount": 3
}
```

---

## 5. Revoke a Share Bundle (Teacher)

### `DELETE /share/:token`

Permanently revokes a share bundle, making the link inaccessible immediately.

**Auth:** Required (teacher JWT)

**Success Response — `204 No Content`**

**Error Response — `404 Not Found`** if the token does not belong to the requesting teacher.

---

## 6. List Teacher's Share Bundles

### `GET /share`

Returns all active (non-expired) share bundles created by the authenticated teacher.

**Auth:** Required (teacher JWT)

**Success Response — `200 OK`:**
```json
[
  {
    "token": "abc12345",
    "shareUrl": "https://portfolio.mitwpu.edu.in/share/abc12345",
    "createdAt": "2026-07-01T00:00:00Z",
    "expiresAt":  "2026-07-31T00:00:00Z",
    "studentCount": 5,
    "isExpired": false
  }
]
```
